# SEN0491 (Laser) Sensor Node

This directory contains the ESPHome configuration for the DFRobot SEN0491 Laser distance sensor.

### Basic info
- ip
    static_ip: 192.168.105.67
    gateway: 192.168.105.123  
- baud rate: 115200
- endpoint : http://{ip}/text_sensor/paired_sensor_data
 !!! endpoint has 500ms update interval!!!
